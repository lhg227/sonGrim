DDC 입주기업 오피스 가상 투어 — 이용 안내

1. 실행
ZIP을 반드시 모두 압축 해제한 뒤 ddc_center_virtual_tour.html 파일을 Chrome, Edge 또는 Whale에서 열어 주세요.
HTML과 ddc_center 폴더는 서로 같은 위치에 두세요. 압축파일 안에서 HTML만 바로 열거나 HTML만 다른 곳으로 옮기면 사진·캐릭터가 표시되지 않습니다.
Three.js와 GLTFLoader는 CDN 링크로 참조하므로 인터넷 연결이 필요합니다.
별도 설치·로그인·웹 서버 없이 HTML을 열어 사용할 수 있습니다.

2. 조작
- WASD / 방향키: 이동
- Shift: 빠르게 이동
- F: 전체 전경 ↔ 1인칭
- 1인칭에서 화면 클릭: 마우스로 둘러보기. Esc: 마우스 해제
- 마우스 드래그: 1인칭 시선 / 전경 회전
- 마우스 휠: 전경 확대·축소
- E: 현재 공간 소개와 실제 참고 사진
- H / 집 모양 버튼: 처음 위치와 전체 전경
- 왼쪽 공간 목록 / 우측 하단 안내도: 공간으로 바로 이동
- 입주 구역 확대: 오피스 구역 전체 보기
- 외관 보기: 지붕과 주황색 상부 입면을 함께 보기
- 우측 상단 캐릭터: 핑크 네모사람 / 제공된 DDC GLB 캐릭터 선택
- 상단 실제 공간 사진: 참고 사진·도면 열기
- 가벼운 화질: 화면 해상도를 낮춰 부하 줄이기
- 모바일·터치 화면: 방향 버튼으로 이동, 화면 드래그로 시선 변경

3. 공간 구성
- 101 호양이네 주인장 / 102 소파이 아트랩 / 103 공헌드레드
- 104 태극기그리자 / 105 혜성디자인 / 106 모양세상
  각 2인실, 4.5m × 4m = 18㎡ 기준 공간
- 107 루아리아 / 108 던다운 스튜디오
  각 4인실, 5m × 5m = 25㎡ 기준 공간
- 교육실: 12개 2인 책상, 24개 의자
- 회의실: 회의 테이블과 10개 의자
- 미디어실: 크로마키, PC, 카메라·삼각대, 조명
- 공유오피스: 공유1–공유4, 공유2–공유5, 공유3–공유6이 중앙 파티션을 두고 마주보는 6개 업무 좌석
- 청년공간 내일스퀘어: 90도 회전한 카페 카운터, 원형 테이블, 창가 목재 마루·낮은 계단
- 1층 로비·행사 공간, 운영 사무실, 다목적실·지원 공간, 벽면 엘리베이터 안내 그림 2대
- 야외 광장, 입주기업 홍보 부스·청년 마켓 부스, 벤치·녹지

4. 제작 기준
제공된 전체 도면·실제 사진·가구 스케치를 바탕으로 재구성한 홍보용 가상 공간입니다.
입주실의 면적은 요청한 18㎡·25㎡를 기준으로 모델링했으며 가로·세로 비율은 시각화용으로 설정했습니다. 건물 전체의 길이·높이, 외벽·상부 매스, 가구·집기 위치는 실측 복원이 아닌 재구성입니다.
기업명과 공유 좌석 표기는 제공 도면 기준입니다. 프로그램과 부스는 행사 공간의 용도를 표현한 예시이며 확정된 행사 일정이나 모집 정보를 뜻하지 않습니다.
층간 이동은 제공하지 않으며 탐색 대상은 지상 1층과 야외 공간입니다. 외관 보기의 상부 건물 매스는 배경 표현입니다.
사진 안내창에서 실제 공간과 가상 공간을 함께 비교할 수 있습니다.

5. 파일 구조
- ddc_center_virtual_tour.html : 실행 파일
- ddc_center_guide.txt : 이 안내문
- ddc_center/ddc_center_app.js : 공간 구성·조작·안내 기능
- ddc_center/ddc_center_style.css : 화면 스타일
- ddc_center/ddc_center_character.glb : 제공된 DDC 캐릭터의 원본 바이너리
- ddc_center/ddc_center_model.js : HTML 직접 실행 시 로컬 GLB 보안 제한을 피하기 위한 동일 모델 데이터
- ddc_center/ddc_center_software.js : WebGL 미지원 환경의 Canvas 호환 렌더러
- ddc_center/ddc_center_*.jpg : 도면과 실제 공간 참고 사진

웹 서버에서는 GLB를 상대 경로로 불러옵니다. HTML을 직접 여는 file:// 환경에서는 함께 포함된 모델 데이터로 표시합니다.
모델과 참조 사진은 별도 외부 사이트에서 가져오지 않으며 포함된 폴더를 사용합니다.

6. 호환성·검증
WebGL 사용 가능 환경에서는 Three.js WebGLRenderer를 사용하며 정적 오브젝트를 묶어 그리기 부하를 줄였습니다.
WebGL을 사용할 수 없는 환경에서는 제공된 참고 HTML의 방식을 바탕으로 한 Canvas 호환 렌더러가 작동합니다. 이 모드는 속도·조명·텍스처·겹침 표현이 WebGL보다 제한됩니다. 원활한 행사 시연은 브라우저 그래픽 가속을 켠 WebGL 환경을 권장합니다.
검사 환경에는 WebGL 컨텍스트가 없어 브라우저 시각 점검은 호환 모드에서 진행했습니다. 전경·1인칭, 공간 선택, 캐릭터 전환, 실제 사진 표시를 점검했습니다. JavaScript 문법·상대 경로 참조와 별도의 통로 연결 검사도 완료했습니다.

수정 반영 사항
- 안내데스크를 입주공간 밖 메인 로비로 이동했습니다.
- 입주공간 입구 옆 기존 데스크 위치는 닫힌 문에 창고라고 표시한 창고입니다.
- 입구 명칭 안내판을 천장 아래로 내려 글자 윗부분이 가려지지 않게 했습니다.
- 교육실 복도 벽에 게시판을 추가했습니다.
- 101~106호 복도 전면은 프레임과 불투명 필름을 적용한 유리 파티션·유리문입니다.
- 공유오피스 좌석을 서로 마주보는 세 쌍으로 재배치했습니다.

추가 수정 사항
- 공유오피스 가구 전체를 창에서 실내 쪽으로 40cm 옮겨 칸막이가 외벽과 겹치지 않도록 했습니다.
- 107·108호 복도 전면도 불투명 필름이 있는 유리로 변경했습니다.
- 교육실 복도 쪽에 뒤쪽 유리문을 추가했습니다.
- 로비 안내데스크 전체를 180도 돌리고 데스크 의자는 삭제했습니다.
- 카페 카운터와 위 장비를 함께 90도 회전하고 카페 안쪽으로 옮겼습니다.
- 창가 소파와 소파 앞 테이블을 없애고 창에 붙은 목재 마루와 낮은 계단을 만들었습니다. 마루에 올라가면 플레이어와 1인칭 시점 높이가 함께 올라갑니다.

추가 수정 사항 (열린 하늘 보기)
- 마루 뒤쪽에 겹쳐 있던 벽을 없애 카페 창가가 이어지도록 했습니다.
- 로비 중앙의 단체 관람용 의자 30개를 삭제했습니다.
- 플리마켓 뒤편은 막힌 벽으로 정리하고 뒤편 공간·설비를 제거했습니다. 입주공간 앞쪽 벽에 엘리베이터 2대를 그린 평면 그림을 배치했습니다. 엘리베이터는 작동하지 않습니다.
- 탐색 중 천장·조명·천장 프레임을 모두 숨겨 1인칭에서도 하늘이 보입니다.
- 로비의 외부 입구를 안내데스크 쪽으로 옮기고 문과 벽이 겹치지 않게 정리했습니다.
- 로비 바닥의 COMMUNITY와 ENTRANCE 영어 표기를 삭제했습니다.
- 입주공간 끝의 EXIT 표기와 출구를 없애고 연속된 창문으로 막았습니다.
- 안내 수치는 입주기업 14, 공실 1로 변경했습니다. 카페도 입주기업에 포함됩니다.

추가 정리

- 야외 바닥의 DDC / STARTUP PLAZA 영문 글자를 삭제했습니다.

입주기업 목록 수정

- 공유오피스 1 - 마케이드 / 공유오피스 2 - 디엔앱스 / 공유오피스 3 - 디나인즈
- 공유오피스 4 - 아르셀리아 / 공유오피스 6 - 또박또박
- 카페 - 청년공간 내일스퀘어 - 청년카페 브나야
- 공용 공간 탭에서는 공유오피스와 카페 항목을 제외했습니다. 공유오피스 5번은 공실로 기업 목록에 포함하지 않습니다.
- 각 공유오피스 기업을 클릭하면 해당 기업의 좌석 앞으로 이동합니다.

센터 로고 적용
- 제공된 가로형 로고를 원본 비율과 색상 그대로 적용했습니다.
- 상단·로딩 화면·안내 카드·사진 안내창·하단의 기관명 표시에 로고를 넣었습니다.
- 입구 안팎 간판, 복도 바닥 안내, 게시판, 교육실, 운영 사무실, 무대 화면 및 외벽 간판에 같은 로고를 적용했습니다.
- 기업명과 방 이름, 접근성 설명·문서 제목은 읽을 수 있는 텍스트로 유지했습니다.
- ddc_center/ddc_center_logo.png는 제공된 원본 로고입니다. ddc_center_brand.js는 HTML 직접 실행에서도 3D 로고를 안전하게 표시하기 위한 같은 이미지 데이터입니다.
