소캐릭터 잡기! — 30초 두더지잡기 / v2 어린이 친화 판정

[실행 방법]
1. ZIP 파일을 폴더째 압축 해제합니다.
2. cow1_game.html 파일을 Chrome, Edge, Whale 등의 브라우저로 엽니다.
3. '게임 시작하기'를 누릅니다. 3초 준비 시간이 지난 뒤 30초 게임이 시작됩니다.
4. 올라오는 소캐릭터를 마우스로 클릭하거나 터치합니다.

별도 설치, 인터넷 연결, 로컬 서버가 필요 없습니다.
HTML과 cow1_assets 폴더는 함께 두세요.
다른 게임과 같은 폴더에 두어도 되도록 HTML, 폴더, JS, CSS,
모델, MTL, 이미지, 저장 키에 cow1 접두사를 사용했습니다.

[게임 규칙]
- 한 판은 정확히 30초입니다. 준비 시간 3초는 포함하지 않습니다.
- 9개 구멍에서 무작위로 소캐릭터가 나옵니다.
- 각 소캐릭터의 등장 시간은 약 0.85~2.05초로 다릅니다.
- 등장부터 퇴장까지 경과한 비율을 10구간으로 나눕니다.
  0~10% 미만: 100점, 10~20% 미만: 90점, ... 90~100% 미만: 10점.
- 망치 아래의 작은 원형 조준점을 소캐릭터에 맞춰 누릅니다.
- 망치 머리가 조준점에 정확히 내려오도록 회전 중심과 위치를 수정했습니다.
- 소캐릭터 몸의 화면 영역에 넓은 풍선망치 머리가 닿으면 잡힙니다.
  몸의 빈틈이나 가장자리 주변을 눌러도 쉽게 잡을 수 있습니다.
- 막 얼굴을 내미는 소캐릭터도 최소 판정 영역을 확보했습니다.
- 잡을 수 있는 대상의 구멍에는 노란 테두리가 표시됩니다.
- 망치가 닿는 순간 노란 파문·큐브·효과음이 함께 나타납니다.
- 빠르게 마우스를 옮겨도 망치는 타격 순간까지 클릭 위치에 고정됩니다.
- 한 소캐릭터는 한 번만 점수가 올라갑니다. 빈 곳을 눌러도 감점은 없습니다.
- 노란 큐브, 떠오르는 획득 점수, 점수판 숫자 애니메이션이 표시됩니다.
- 풍선망치는 커서를 따라 움직이며 클릭하면 휘둘러집니다.
- 종료 후 결과와 최고 기록을 확인하고 다시 도전할 수 있습니다.
- 최고 기록은 사용한 브라우저에 저장됩니다. 효과음은 우측 상단에서 끌 수 있습니다.
- 다른 탭으로 이동해도 시간은 흐릅니다.

cow1_assets/cow1_model.js    오프라인 실행용 원본 OBJ·MTL 데이터

소 캐릭터 OBJ와 MTL 재질 색상이 적용되어 있습니다.
이 색상을 읽어 모델에 적용합니다. HTML 더블클릭 실행 시 파일 접근 제한을
피하기 위해 OBJ·MTL 원문을 cow1_model.js에도 포함했습니다.
모델을 교체하려면 OBJ·MTL뿐 아니라 cow1_model.js의 데이터도 갱신해야 합니다.

[실행이 되지 않을 때]
- ZIP 안에서 직접 열지 말고 전체 파일을 압축 해제해 주세요.
- 브라우저의 WebGL / 그래픽 가속이 활성화되어 있어야 합니다.
- 그래픽 가속 설정을 바꾼 뒤에는 브라우저 재시작이 필요할 수 있습니다.

[검증 범위]
원본 OBJ·MTL 파싱, 9개 구멍의 화면 좌표 기반 넉넉한 타격 판정,
1048px·360px 화면에서 가장자리 밖 28px 클릭 성공, 조준점과 망치 위치 일치,
타격 순간 위치 고정, 타격 파문 표시, 빈 곳 클릭 시 득점 방지,
100~10점 전 구간, 중복 획득 방지, 30초 종료, 최고 기록 저장,
재시작 초기화를 코드로 검증했습니다.
제작 환경의 미리보기 브라우저에서 WebGL이 비활성화되어 있어
실제 GPU 화면 렌더링과 효과음 재생에 대한 브라우저 검증은 완료하지 못했습니다.
